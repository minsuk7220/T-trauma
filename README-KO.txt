(T)트라우마심리상담연구소 홈페이지 — 코드 및 배포 안내

이 압축파일은 현재 제작된 홈페이지의 HTML, CSS, JavaScript와 이미지 원본을 담고 있습니다.
특정 사이트 제작 서비스에 종속되지 않는 정적 웹사이트입니다.
Node.js 설치, npm 설치, 빌드 과정, 데이터베이스 없이 사용할 수 있습니다.

1. 내 컴퓨터에서 열어보기

압축파일을 먼저 모두 풀고 index.html을 브라우저에서 여세요.
압축파일 내부에서 index.html만 따로 실행하면 이미지나 스타일이 제대로 표시되지 않을 수 있습니다.
Google Fonts는 인터넷 연결이 필요하며, 불러오지 못하면 기본 글꼴로 표시됩니다.
주소 복사는 브라우저 권한과 HTTPS 환경에 따라 제한될 수 있습니다.

2. 실제 홈페이지로 운영하기

정적 파일을 제공할 수 있는 웹호스팅의 공개 폴더에 아래 6개 파일을 그대로 업로드하세요.
index.html이 홈페이지 루트에 위치하도록 하고 파일 이름과 상대 경로를 유지하세요.
호스팅에 연결할 도메인을 설정하고 HTTPS를 활성화하면 방문자가 접속할 수 있습니다.
호스팅 업체에 따라 공개 폴더 이름과 도메인 연결 절차는 다릅니다.
FTP/SFTP 방식 또는 호스팅의 파일 업로드 기능을 사용할 수 있습니다.
이 안내문은 운영 서버에 업로드하지 않아도 됩니다.

3. 파일 구성

index.html              화면 구성, 연구소 소개, 연락처, 주소, 활동 소개
style.css               글꼴, 색상, 여백, 모바일 화면, 내부 사진 표시 영역
app.js                  모바일 메뉴, 상담 안내 팝업, 주소 복사
favicon.svg             브라우저 탭의 T 아이콘
hero.webp               메인 화면의 분위기 이미지
center-blog-original.png 제공된 블로그 캡처 원본; CSS로 내부 공간 사진 부분을 표시
README-KO.txt           이 안내문

4. 현재 이용 가능한 기능

- PC와 모바일 화면
- 상담 분야별 안내 팝업
- 자주 묻는 질문 펼치기와 접기
- 전화번호 클릭: 010-2340-7220
- 네이버 지도와 블로그 링크
- 주소 복사 (지원되는 브라우저 및 HTTPS 환경)

전화 버튼은 기기에 설정된 전화 앱을 엽니다.
온라인 예약 신청서, 예약 내역 저장, 관리자 페이지, 알림 발송, 결제 기능은 포함되어 있지 않습니다.
실제 상담 일정은 방문자가 전화로 문의하는 운영 방식입니다.
이러한 온라인 접수 기능을 추가하려면 별도의 서버 또는 예약 서비스 연동이 필요합니다.

5. 내용을 수정하는 방법

UTF-8을 지원하는 코드 편집기에서 파일을 여세요.
연구소명, 소개, 주소, 활동 문구: index.html
상담 안내 팝업 문구: app.js의 programs 배열 및 programs.push 부분
색상과 디자인: style.css

전화번호를 바꿀 때는 index.html과 app.js에서
표시용 010-2340-7220 및 연결용 01023407220을 모두 찾아 수정하세요.
주소를 바꿀 때는 index.html의 표시 주소와 네이버 지도 링크,
app.js의 addressText를 함께 수정하세요.

메인 사진을 바꾸려면 hero.webp를 교체하거나 index.html의 해당 src를 수정하세요.
현재 메인 사진은 실제 연구소 사진이 아닌 분위기 이미지이며 화면에 그 사실을 표시하고 있습니다.
center-blog-original.png는 전체 블로그 캡처입니다. 사진 표시 범위는 style.css의
.interior-frame 및 .interior-frame img에서 정합니다.
다른 크기의 이미지로 교체할 때는 해당 표시 범위도 함께 조정하세요.

연구소 내부와 활동 소개는 제공된 캡처를 바탕으로 구성했습니다.
프로그램 일정과 비용은 전화로 확인하도록 안내되어 있습니다.

6. 수정 후 반영하기

변경한 파일을 운영 서버의 같은 위치에 덮어쓰면 됩니다.
기존 화면이 보이면 브라우저에서 새로고침하거나 캐시를 지운 뒤 확인하세요.
HTTPS 페이지에서 전화 연결, 지도 이동, 모바일 메뉴, 팝업과 주소 복사를 확인하세요.

현재 사이트의 운영 정보나 접근 키는 이 압축파일에 포함되지 않습니다.
독립적인 호스팅에 이 파일들만 올려서 운영할 수 있습니다.
