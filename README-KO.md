# (T)트라우마심리상담연구소 — 예약·관리·결제 버전

기존 홈페이지에 의성점, 오미경 센터장 소개, 예약 저장, 관리자 화면과 토스페이먼츠 카드/간편결제 연동을 추가한 전체 코드입니다.

## 주요 주소

- `/` 연구소 홈페이지, 대구·의성 지점 안내
- `/reservation` 온라인 예약 신청
- `/booking` 신청 시 발급된 전용 링크로 예약 조회
- `/admin` 관리자 페이지
- `/payment-result` 결제 승인 결과 확인

예약은 '접수 대기 → 관리자 일정·금액 확인 → 예약 확정 → 결제 → 상담 종료' 순서로 운영합니다.
신청자가 입력하는 시간은 희망 시간이며, 자동 예약 확정이 아닙니다. 관리자 확정 시간은 09~20시 정각 기준이며, 같은 지점·날짜·시간에는 한 건만 확정됩니다. 이 버전은 한 건을 한 시간 단위로 관리합니다.

## 포함된 기능

- 예약을 서버 데이터베이스에 저장
- 대구·의성점 선택, 신청 정보 검증, 중복 제출 방지용 요청 키
- 무작위 비밀 링크로 신청자 자신의 예약 상태 조회
- 관리자 인증, 지점별 조회 및 페이지 이동
- 상담 일정·금액·상태 관리
- 결제 주문 생성, 서버 금액 검증, 결제기관 승인 확인
- 미승인 결제 주문 닫기, 승인 상태 재조회, 전액 환불
- 종료·취소된 예약의 이름과 전화번호 삭제
- 관리자에서 개인정보 보유 기간과 취소·환불 기준 설정
- Node.js/SQLite 독립 실행 및 Cloudflare Worker/D1 실행 구조

문자·이메일 자동 발송, 상담사별 달력, 부분 환불, 회원가입, 진료기록 관리 기능은 포함되어 있지 않습니다. 결제기관 승인·환불은 실제 키와 결제기관 접속이 있어야 작동합니다. 테스트에서 사용한 결제기관 응답은 모의 응답이며, 실제 결제를 수행하지 않았습니다.

## 시작하기 — 내 서버에서 독립 운영

기존 정적 HTML 버전과 달리 서버가 필요합니다. HTML 파일만 올리는 정적 호스팅에서는 예약 저장과 관리자 API가 작동하지 않습니다.

1. Node.js 24 이상을 설치합니다.
2. 압축을 푼 프로젝트 폴더에서 `npm ci`를 실행합니다.
3. `.env.example`을 `.env`로 복사합니다.
4. 아래 항목을 `.env`에 설정합니다.
   - `AUTH_MODE=token`
   - `ADMIN_TOKEN=` 뒤에 32자 이상의 무작위 관리자 토큰
   - `PUBLIC_ORIGIN=http://localhost:3000` (운영 시 실제 HTTPS 도메인)
5. `npm run build`를 실행합니다.
6. `npm start`를 실행하고 `http://localhost:3000`에 접속합니다.
7. `/admin`에서 관리자 토큰을 입력합니다.

관리자 토큰 생성 예:

```sh
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

생성한 값은 `.env`에만 입력하고 공유하거나 공개 코드 저장소에 올리지 마세요. 관리자 토큰은 페이지 메모리에만 유지되며 새로고침하면 다시 입력해야 합니다. 독립 Node 서버는 전달된 ChatGPT 인증 헤더를 신뢰하지 않고 토큰 인증을 사용합니다.

데이터는 `.data/reservations.sqlite`에 영구 저장됩니다. 서버 재시작 시 유지됩니다. 운영 환경은 파일이 유지되는 디스크가 필요하며, 이 폴더를 백업 대상에 포함하세요. SQLite가 실행 중이라면 SQLite 백업 기능 또는 일관된 볼륨 스냅샷 방식으로 백업하세요.

로컬 서버는 127.0.0.1에 바인딩합니다. 인터넷 공개 운영은 HTTPS 리버스 프록시 뒤에 배치하고 `PUBLIC_ORIGIN`을 그 외부 HTTPS 주소로 맞추세요. 결제 결과 URL과 요청 출처 검증에 이 값을 사용합니다. API를 캐시하지 마세요.

## 관리자에서 먼저 설정할 내용

'온라인 접수 · 결제 운영 설정'을 펼칩니다.

- 개인정보 보유 기간: 연구소가 실제로 운영할 기간을 입력합니다. 이 항목을 저장하면 온라인 예약 접수가 열립니다. 실제 보유 기간이 지난 예약의 이름·연락처는 관리자에서 삭제해야 하며, 자동 파기는 구현되어 있지 않습니다. 예약/거래 기록의 보존·삭제 정책은 운영자가 관리합니다.
- 취소·환불 기준: 실제 기준을 입력합니다. 결제 API 키와 이 기준이 모두 있어야 온라인 결제 버튼이 활성화됩니다.

이 문구들은 연구소의 운영 정책이므로 임의로 확정하지 않았습니다. 설정 전에는 홈페이지와 관리자 기능을 열어볼 수 있지만 개인정보를 입력하는 온라인 접수는 준비 중으로 표시합니다.

실제 사이트에서는 현재 소유자 계정으로 관리자 페이지에 접근할 수 있습니다. 외부 독립 서버는 위의 토큰 인증을 사용하세요.

## 결제 연결 — 토스페이먼츠

구현은 토스페이먼츠 SDK v2의 카드/간편결제 `payment().requestPayment()`와 서버 승인 API를 사용합니다. 결제위젯용 키와 혼용하지 말고 이 API에 맞는 API 개별 연동 키를 사용하세요.

`.env` 또는 운영 호스팅의 비밀 환경변수에 다음을 설정합니다.

- `TOSS_CLIENT_KEY`: 브라우저용 클라이언트 키
- `TOSS_SECRET_KEY`: 서버 전용 시크릿 키
- `PUBLIC_ORIGIN`: 결제 후 돌아올 사이트의 HTTPS 주소

테스트 키로 결제와 환불을 먼저 확인한 후, 계약과 가맹점 설정이 완료되면 해당 가맹점의 라이브 키로 교체하세요. 클라이언트 키와 시크릿 키는 같은 상점·같은 모드여야 합니다. 시크릿 키는 public 폴더나 클라이언트 JavaScript에 넣지 마세요.

관리자가 예약을 확정하고 금액을 저장하면 신청자의 조회 링크에 결제 버튼이 나타납니다. 결제 금액은 서버 저장 금액으로 검증하며, 브라우저가 보낸 '성공' 정보만으로 결제 완료로 저장하지 않습니다. 카드 정보는 토스페이먼츠 결제창에서 입력합니다.

네트워크 오류가 발생한 경우 중복 결제를 진행하지 말고 관리자에서 '결제 상태 조회'를 누르세요. 결제 결과 화면에도 재확인 기능이 있습니다. 외부에서 결제나 환불 상태를 바꾸었다면 관리자에서 재조회하여 동기화하세요. 이 버전에는 자동 웹훅 동기화가 없으며, 결제 화면 이탈 등으로 확인이 끝나지 않은 거래는 관리자가 재조회해야 합니다.

관리자가 직접 금액을 바꾸거나 예약을 취소해야 하는데 미승인 주문이 남아 있다면, 고객에게 결제창을 닫도록 안내한 뒤 '미승인 결제 주문 닫기'를 사용하세요. 승인 진행 중이거나 완료된 결제는 이 기능으로 닫을 수 없습니다.

전액 환불은 관리자 확인과 사유 입력을 거쳐 결제기관 API로 처리됩니다. 거래 승인·환불 상태가 불확실하면 토스페이먼츠 관리자와 함께 확인하세요. 환불을 포함한 거래기록은 연락정보 삭제와 별도로 유지됩니다.

- https://docs.tosspayments.com/reference

## Sites / Cloudflare 호환 구조

- `server/api.mjs`: 예약·관리자·결제 API
- `server/worker.mjs`: Worker 진입점
- `scripts/build.mjs`: 정적 자산을 포함한 Worker 및 마이그레이션 생성물 구성
- `.openai/hosting.json`: 논리 DB 바인딩 (`DB`)
- `db/schema.ts`: DB 스키마
- `drizzle/`: 생성된 SQL 마이그레이션과 메타데이터
- `scripts/sqlite-adapter.mjs`: 독립 Node 서버용 SQLite 어댑터 및 마이그레이션 실행기
- `tests/api.test.mjs`: 저장·접근 제한·결제 검증 테스트

Worker 환경에서는 D1의 `DB` 바인딩과 마이그레이션 적용이 필요합니다. 다른 호스팅에서 관리자를 보호할 때는 `AUTH_MODE=token`을 사용하세요. `AUTH_MODE=sites`는 Sites의 신뢰된 인증 헤더가 제공되는 환경 전용입니다. 외부에서 임의로 보낸 인증 헤더를 신뢰하도록 설정하면 안 됩니다.

코드 ZIP의 `.openai/hosting.json`에는 기존 사이트 식별자나 계정 정보가 없습니다. 다른 사용자에게 관리자 권한을 주려면 운영 환경의 관리자 설정을 별도로 변경해야 합니다.

## 지점 및 소개 내용

의성점과 센터장 오미경님의 제공된 학력·경력·자격·연구 내용을 추가했습니다.
대구와 의성점은 같은 상담 번호 010-2340-7220을 사용합니다. 의성점 상세 주소는 아직 확인 중으로 표시했습니다.
자격명 '공임임상트라우마전문가'는 사용자 원문대로 반영했습니다. 의도한 명칭이 '공인임상트라우마전문가'라면 `public/index.html`에서 바꿔주세요.

## 수정 및 검증

홈페이지 내용은 `public/index.html`, 디자인은 `public/style.css`와 `public/forms.css`, 각 화면 동작은 해당 JavaScript에서 수정합니다. 변경 후 `npm test`, `npm run build` 순서로 확인하세요. DB 변경 시 `npm run db:generate`로 새 마이그레이션을 생성하고 이미 적용된 마이그레이션은 수정하지 마세요.

공개 호스팅과 외부 결제 연결, 결제업체 심사·계약, 실제 운영 정책 확정은 각각 별도 운영 설정입니다. 현재 배포된 사이트의 열람 범위는 기존 소유자 전용 설정을 유지합니다.


## 2026-09-15 화면 및 경로 수정

- PC 첫 화면에서 뷰포트 전체 폭을 왼쪽 여백으로 사용하던 규칙을 제거했습니다.
- 김규식·오미경·김혜린 소개를 사진 카드 세 개로 통합했습니다. PC 마우스 올리기, 클릭 고정, 키보드 포커스·Enter·Escape, 모바일 터치를 지원합니다.
- 김규식·오미경은 제공된 사진, 김혜린은 이력서에 포함된 사진을 사용했습니다. 김혜린의 생년월일·개인 연락처·이메일·주소·학점은 웹사이트에 게시하지 않았습니다.
- 화면 링크를 상대 경로의 .html 파일로 변경했습니다. 정적 미리보기에서도 예약 페이지 자체가 열립니다. 단, 예약 저장과 관리·결제는 여전히 실제 서버가 필요합니다.
- Windows에서는 start-server.cmd를 실행하면 빌드 후 로컬 예약 서버를 실행합니다. Node.js 24 이상이 필요합니다. 관리자 토큰과 결제 키 설정은 앞의 안내를 따라주세요.
- ZIP 최상위 index.html은 화면 미리보기용 진입 파일입니다. 실제 예약 기능 확인은 http://localhost:3000 에서 진행하세요.
- 서버는 /reservation 과 /reservation.html 양쪽 주소를 모두 지원합니다.
